## 🇪🇸 Español

¡Gracias por considerar apoyar el desarrollo de **NodeTerm**! 

NodeTerm es un espacio de trabajo de acceso remoto *all-in-one* gratuito y de código abierto que integra SSH, RDP, VNC, SFTP y capacidades avanzadas de automatización con **IA y el protocolo MCP (Model Context Protocol)**.

### 🚀 ¿Por qué patrocinar el proyecto?

- ⚡ Garantizar el desarrollo continuo y mantenimiento activo de NodeTerm.

- 🤖 Desarrollar nuevos servidores y herramientas para la integración con IA (Cursor, Antigravity, Claude, etc.).
- 🌐 Cubrir costes de infraestructura, firmas de código y construcción de versiones multiplataforma.
